## Approach
- **Stack**: Bash, Docker, GitHub Actions, Markdown
- **Testing**: `bash test.sh` per unit (TDD enabled in config); `bash verify.sh` for build verification
- **Patterns**: Follow existing unit structure (`setup.sh`, `test.sh`, `manual.sh`); use shared validators
- **CI**: Single workflow `ci.yml` with matrix over 26 unit directories; fail-fast on CORE failures
- **Hardening**: Dockerfile `USER estudiante`, `--cap-drop=ALL --cap-add=NET_ADMIN,NET_RAW,SETUID,SETGID`, `--security-opt=no-new-privileges`
